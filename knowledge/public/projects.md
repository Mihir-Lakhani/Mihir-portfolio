# Project case studies

## 5G Handover with Stability-Aware Machine Learning

This project is a stability-aware machine learning framework for proactive handover decisions in 5G networks. It combines prediction, trend smoothing, and volatility control so that handover decisions can be made early without becoming unstable in noisy mobility conditions.

The public portfolio describes the work as a mobility-management framework using real-world KPI traces and a stability-aware risk mechanism.

Canonical portfolio page: `/mobility`.

## Cardio Risk Predictor

The Cardio Risk Predictor is an interpretable cardiovascular-risk project built around a decision-tree approach and clinical and lifestyle data. The project demonstrates preprocessing, model evaluation, data visualization, and explainable model thinking without treating the result as medical advice.

Canonical portfolio page: `/cardio`.

Verified public repository: `https://github.com/Mihir-Lakhani/Cardiovascular-Disease-Risk-Prediction`.

## Digital Twin Fleet Smart Vehicle

The Digital Twin Fleet Smart Vehicle project is an IoT digital-twin platform for vehicle tracking and analytics. It uses Eclipse Ditto and containerized deployment concepts, including Docker and Kubernetes, to explore edge-cloud synchronization and fleet-management workflows.

Verified public repository: `https://github.com/Mihir-Lakhani/fleet-digital-twin-eclipse-ditto`.

## Closed Loop Automation / SLA Violation Predictor

This telecom machine-learning project focuses on predicting service-level-agreement risk from QoS logs. The portfolio describes SHAP-based root-cause analysis, low-latency alerting, and a closed-loop feedback demonstration at Nokia Campus Connect 2025.

## Parkinson's Disease Detection

This research-oriented project explores early Parkinson's disease detection using EEG signals and an ITDO Attention DenseNet approach. It combines signal preprocessing, feature extraction, attention mechanisms, and optimization techniques.

## Fraud Transaction Detector

The Fraud Transaction Detector is a real-time financial-fraud classification project. Its public description focuses on identifying rare suspicious transactions while minimizing false positives and keeping deployment lightweight.

Verified public repository: `https://github.com/Mihir-Lakhani/fraud-detection-xgboost-shap`.

## Explainable AutoML System

The Explainable AutoML System is an in-progress end-to-end machine-learning workflow. It is designed to automate cleaning, model selection, feature engineering, hyperparameter tuning, model-specific preprocessing, and explainability through SHAP-style analysis.
